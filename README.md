# Movie Ticket Booking Calculator

A simple Java console application that calculates the final amount for a movie ticket booking based on ticket cost, number of tickets, snack cost, discount, and tax.

## Project Overview

This project was created as part of my step-by-step Java learning journey.

The application takes booking details from the user and calculates:

* Ticket cost
* Snack cost
* Subtotal
* Discount amount
* Tax amount
* Final payable amount

## Concepts Practiced

* Variables and Data Types
* Arithmetic Operators
* Assignment Operators
* Input using `Scanner`
* Basic calculations
* `printf()` formatted output
* Percentage calculations

## How to Run

1. Make sure Java JDK is installed.
2. Open the project folder in VS Code.
3. Compile the program:

```bash
javac Main.java
```

4. Run the program:

```bash
java Main
```
